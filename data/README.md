# Data Directory Structure

This directory contains all data used and generated by the scraping system.

## 📁 Folders

### `inputs/`
Source data files:
- `airports.csv` - Airport database with IATA codes
- `cities.csv` - Cities to scrape from
- `festivals/` - Festival data from placetodance.com
  - `festivals_data/{Month}.csv` - Festival info by month
  - `festivals_data/events/{Month}/` - Flight prices for each festival

### `outputs/`
Generated data:
- `final_sheets/{YYYYMMDD}/` - Merged CSV files ready for upload
- `videos/` - Generated video files

### `temp/`
Temporary files (can be deleted):
- `ready_sheets/{YYYYMMDD}/` - Individual XLSX files before merge

## 🔄 Data Flow

```
1. festivalFound.js   → inputs/festivals/festivals_data/{Month}.csv
2. kayakFestivals.js  → inputs/festivals/festivals_data/events/{Month}/{event}.csv
3. kayakExplore.js    → temp/ready_sheets/{date}/*.xlsx
4. processData.js     → outputs/final_sheets/{date}/all_merged_{date}.csv
5. Upload             → Supabase
```
